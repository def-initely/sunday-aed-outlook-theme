# Sunday AED Outlook Express theme

A warm, retro Outlook Express-inspired Vencord CSS theme.

## Files
- `sunday-aed-outlook.theme.css` — the theme
- `assets/character.png` — transparent Roblox character background
- `assets/aed.png` — AED banner image

## Publish to GitHub
Create a **public** repository named `sunday-aed-outlook-theme` under the account `def-initely`, then upload the CSS file and the whole `assets` folder while preserving the folder structure. Commit the files to the `main` branch.

The CSS uses these raw URLs:
- `https://raw.githubusercontent.com/def-initely/sunday-aed-outlook-theme/main/assets/character.png`
- `https://raw.githubusercontent.com/def-initely/sunday-aed-outlook-theme/main/assets/aed.png`

If you choose a different repository name or account, update those URLs in the CSS.

## Enable in Vencord
Once the repository is public and committed, copy the raw CSS URL:
`https://raw.githubusercontent.com/def-initely/sunday-aed-outlook-theme/main/sunday-aed-outlook.theme.css`

Add it under Vencord > Themes > Online Themes if that option is available in your setup. Refresh Discord after adding it.

Note: Discord's internal selectors can change; some visual adjustments may be needed for your Vencord build.
